# Demo Dossier

Small synthetic MDR/IVDR-style dossier used by the offline ingestion tests and
the local demo path. Files are real binary documents readable by `python-docx`,
`pypdf`, and `openpyxl`.

## Files

- `CER.docx` - placeholder Clinical Evaluation Report with headings, a few
  paragraphs containing seeded numeric claims and citations, and a small
  endpoint summary table.
- `GSPR_mapping.xlsx` - one sheet (`GSPR`) with a header row and five GSPR
  requirement rows that reference other dossier documents.
- `bibliography/source-study.pdf` - minimal two-page PDF carrying the source
  passage the CER cites.
- `README.md` - this file. Always treated as `UNSUPPORTED_FILE_TYPE` by the
  ingestion loader.

## Expected verify summary

```bash
locus verify fixtures/demo_dossier --out tmp/demo
```

```text
18 claims, 5 citations, 3 sources, 18 evidence links, 7 findings, 104 graph records
```

Equivalent runner: `python scripts/run_demo.py --out tmp/demo`.

## Regenerating

The three binary documents are generated by `scripts/seed_demo_fixture.py`. Run
it from the repo root whenever the fixture content needs to change:

```bash
python scripts/seed_demo_fixture.py
```

The script overwrites the three files in place and runs offline.
